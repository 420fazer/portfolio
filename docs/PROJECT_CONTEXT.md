# Контекст проекта Portfolio

Актуальность: 20 ноября 2026 года.

## Назначение
Личное дизайн-портфолио, статический сайт без сборки и дополнительных сервисов. Репозиторий: https://github.com/420fazer/portfolio.

## Архитектура
index.html — разметка и RU/EN тексты; style.css — стили и дизайн-токены; script.js — тема, язык, анимации, контакты и прокрутка; favicon.svg — иконка NT®. assets/ — будущие медиаматериалы; projects/ — будущие страницы кейсов. Flow, Orbit, Form и Basis пока представлены на главной, в develop создан демонстрационный кейс Flow (projects/flow/index.html).

## Ветки и публикация
- main — согласованная версия: https://420fazer.github.io/portfolio/
- develop — разработка: https://420fazer.github.io/portfolio/preview/
- .github/workflows/pages.yml собирает обе ветки в единый артефакт: main в корень, develop в preview/. Запуск при push в любую из двух веток или вручную.
- Последний проверенный повторный запуск develop (44705703507) завершился успешно. Визуальный тест в браузере не проведён.
- Предпросмотр публичный, robots.txt не является контролем доступа. Обе ветки способны инициировать публикацию всего артефакта; доступ на запись только доверенным лицам.

## Настройки GitHub
Со слов владельца настроены: Pages Source GitHub Actions, HTTPS, Actions Allow all, retention 90 дней, стандартные права токена Read, создание/одобрение PR токеном выключено, окружение github-pages допускает только main и develop. Workflow явно запрашивает contents: read, pages: write, id-token: write. Настройки напрямую не аудированы. 2FA и защита веток отдельно не подтверждены.

## Процесс
Изменения в develop → проверка предпросмотра → согласование пользователя → перенос в main. История Git для откатов. Документация публична, секреты запрещены. Документация исключается из артефакта обновлённым workflow; изменение уже перенесено в main.

## Дизайн (develop)
Сетка проектов равномерная: две одинаковые колонки от 768 px, одна ниже; обложки 4:3, горизонтальный промежуток 32 px на двух колонках, вертикальный 48 px. Визуальная проверка и перенос в main ожидаются.

Страница Flow использует общие стили и скрипт, RU/EN, обе темы. Реальные материалы и результаты не добавлены. Визуальная проверка ожидается.

## Кеширование ресурсов (develop)
.github/version_assets.py при сборке добавляет хеш содержимого к относительным CSS/JS ссылкам на всех HTML-страницах, включая кейсы. Preview включён сразу; production только после переноса в main. Права workflow не изменены.

Типографика Flow согласована с главной: общие правила H1, H2, H3, вводного и основного текста; новые визуальные стили требуют согласования.

Согласованное исключение из общей типографики: Navigation CTA (`.navigation-cta`) для перехода к другим проектам в конце кейса, Manrope, адаптивный размер 32–80 px (6vw), letter-spacing −.04em. Переиспользовать в будущих кейсах.

В Flow три принципа входят в секцию «Подход»: общий разделитель после секции, расстояние до карточек 48 px на desktop и 32 px на mobile через существующие токены.

Эксперимент главной (develop): существующее имя в hero набрано прописными Manrope 700 с плотным межстрочным интервалом .92 и трекингом −.055em по согласованному референсу. Сетка, тексты, темы и типографика кейсов сохранены.

Эксперимент полноэкранного hero: минимальная высота равна доступной высоте viewport (svh) за вычетом шапки и навигации; содержимое центрировано по вертикали, существующие отступы, сетка и типографика сохранены. При нехватке высоты секция может расти.
