# Контекст проекта Portfolio

Актуальность: 20 ноября 2026 года.

## Назначение
Личное дизайн-портфолио, статический сайт без сборки и дополнительных сервисов. Репозиторий: https://github.com/420fazer/portfolio.

## Архитектура
index.html — разметка и RU/EN тексты; style.css — стили и дизайн-токены; script.js — тема, язык, анимации, контакты и прокрутка; favicon.svg — иконка NT®. assets/ — будущие медиаматериалы; projects/ — будущие страницы кейсов. Flow, Orbit, Form и Basis пока представлены на главной, отдельные кейсы не созданы.

## Ветки и публикация
- main — согласованная версия: https://420fazer.github.io/portfolio/
- develop — разработка: https://420fazer.github.io/portfolio/preview/
- .github/workflows/pages.yml собирает обе ветки в единый артефакт: main в корень, develop в preview/. Запуск при push в любую из двух веток или вручную.
- Последний проверенный повторный запуск develop (44705703507) завершился успешно. Визуальный тест в браузере не проведён.
- Предпросмотр публичный, robots.txt не является контролем доступа. Обе ветки способны инициировать публикацию всего артефакта; доступ на запись только доверенным лицам.

## Настройки GitHub
Со слов владельца настроены: Pages Source GitHub Actions, HTTPS, Actions Allow all, retention 90 дней, стандартные права токена Read, создание/одобрение PR токеном выключено, окружение github-pages допускает только main и develop. Workflow явно запрашивает contents: read, pages: write, id-token: write. Настройки напрямую не аудированы. 2FA и защита веток отдельно не подтверждены.

## Процесс
Изменения в develop → проверка предпросмотра → согласование пользователя → перенос в main. История Git для откатов. Документация публична, секреты запрещены. Документация исключается из артефакта обновлённым workflow; пока изменение находится в develop, старый workflow main ещё может её публиковать при запуске из main.
