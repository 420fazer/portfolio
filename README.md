# Portfolio

Статический сайт на HTML, CSS и JavaScript. Публикация: GitHub Pages, ветка `main`, корень репозитория.

## Структура

- `index.html` — главная страница и двуязычные тексты.
- `style.css` — дизайн-токены, темы, компоненты и адаптивность.
- `script.js` — язык, тема, контакты, анимации и прокрутка.
- `favicon.svg` — иконка вкладки.
- `assets/` — будущие изображения, иконки, шрифты и видео.
- `projects/` — будущие страницы кейсов.

## Разработка

Откройте `index.html` в браузере или запустите `python -m http.server 8000` в корне репозитория. Сборка не требуется. Для новых страниц используйте относительные пути к общим ресурсам. Перед подключением общего скрипта к новым страницам проверьте наличие элементов, которые он ожидает (или добавьте проверки).

Кейсы Flow, Orbit, Form и Basis пока находятся на главной странице; отдельные страницы не опубликованы.
